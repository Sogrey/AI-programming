# 你画我猜游戏

这是一个简单的"你画我猜"网页游戏，玩家可以在画布上绘画，并让其他人猜测所画内容。

## 功能特点

- 绘画功能：使用鼠标在画布上自由绘画
- 多种颜色选择：黑色、红色、蓝色、绿色、黄色
- 可调节画笔大小：从1到50像素
- 词语提示系统：显示需要绘画的词语
- 猜词功能：可以输入猜测并提交
- 其他功能：
  - 清除画布
  - 更换词语
  - 放弃猜测选项

## 技术栈

- HTML5：页面结构和Canvas绘图
- CSS：样式和布局
- JavaScript：交互逻辑和游戏功能

## 使用方法

1. 打开 index.html 文件在浏览器中运行游戏
2. 画图者查看"要画的词"并在画布上绘制
3. 猜词者在输入框中输入猜测并提交
4. 使用工具栏调整颜色和画笔大小
5. 可以随时清除画布或更换新词

## 文件结构

- `index.html` - 游戏的HTML结构
- `style.css` - 游戏的样式表
- `script.js` - 游戏的JavaScript逻辑
